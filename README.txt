FREE PUBLISHING OPTION:
You can publish the files using GitHub Pages:
- Create/sign in to GitHub.
- Create a new public repository named prime-site (or another available name).
- Upload the contents of this folder (not the ZIP itself) to the repository root.
- In repository Settings > Pages, select deploy from a branch, choose main and /(root), then save.
- GitHub will provide a public URL after deployment. Exact menus may change.
A custom domain is optional and usually costs money.
